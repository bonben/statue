# Statue

Détecteur de mouvement par la caméra, pour les jeux d'immobilité (1, 2, 3 soleil, statue musicale…).

On lance la surveillance, et chaque mouvement dans le champ (ou dans la zone choisie) déclenche un son et ajoute 1 au compteur. Tout se passe dans le navigateur : aucune image n'est envoyée ni enregistrée.

- Installable sur l'écran d'accueil (PWA), fonctionne hors ligne.
- Analyse légère (image réduite à 80 px de large, ~12 images/s) pour les petits téléphones.
- Réglages : sensibilité, délai avant départ, pause après détection, son, zone surveillée.
